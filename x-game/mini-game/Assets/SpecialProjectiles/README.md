# 特殊攻击美术资源说明

每个目录代表一种和普通子弹不同的攻击表现。后续替换美术时，优先放入 `1.png`，游戏会自动读取。

- `00_普通子弹`：备用普通弹，不影响当前按战机区分的子弹。
- `01_跟踪导弹`：需要有明显弹头方向，建议朝上或朝右都可以，代码会按飞行方向旋转。
- `02_脉冲波`：短促能量波或弧形弹，用于脉冲弹匣。
- `03_重型巨弹`：低速大弹或炮弹，命中会有小范围冲击。
- `04_弹球弹丸`：边界反弹弹体，建议轮廓区别于普通圆弹。
- `05_影子分身`：半透明或残影子弹。
- `06_分裂碎片`：击杀分裂出的碎片弹。
- `07_连锁弹跳`：命中后跳转到其他目标的弹体。
- `08_护盾反弹`：由护盾把敌弹弹回时使用。
