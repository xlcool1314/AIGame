# 循环战机三选一图标需求

用途：放置局内升级“三选一”卡牌上显示的图标。

## 文件放置规则

- 文件夹：`mini-game/Assets/三选一图标`
- 推荐尺寸：`512x512 PNG`，透明底或深色底均可。
- 推荐命名：`中文名_UpgradeId.png`
- 兼容命名：`UpgradeId.png`
- 示例：`跟踪导弹_SeekerRack.png`
- 游戏读取优先级：先读 `中文名_UpgradeId.png`，找不到再读 `UpgradeId.png`。

## 统一风格

- 整体：简洁科幻、深色底、细线、高辨识度。
- 构图：一个中心符号即可，避免复杂背景。
- 颜色：黑/深灰底，白色主体，红色/青色/金色作为强调。
- 读图目标：缩到 `64x64` 仍能看出是什么机制。
- 避免：大段文字、数字、过细碎零件、复杂渐变、写实人物。
