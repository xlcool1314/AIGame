# Drone Art

当前游戏里需要单独设计美术的无人机按“视觉类别”分为 2 个本体类别，另有 1 个技能特效类别：

1. `01_PlayerSupportDrone`
   - 通用支援无人机。
   - 来源：局外成长“无人机坞”、公共升级“月尘伴飞”。
   - 所有非环序角色获得的环绕无人机都优先使用这一类。

2. `02_KairoSwarmDrone`
   - 环序专属蜂群无人机。
   - 来源：环序初始无人机、环序专属升级“无人机舱 / 蜂群同步 / 蜂群覆写 / 蜂群中继”。
   - 这是环序角色的核心视觉，建议和通用无人机明显区分。

3. `03_KairoCommandBurst`
   - 环序技能的无人机指令/齐射特效。
   - 不是常驻无人机本体，而是按空格技能时出现的短时指令特效，可选做。

说明：
- Boss“蜂群母舰”目前召唤的是普通敌人，不需要额外设计小无人机。
- 夜幕的“虚空轨道 / 重力刃”是轨道刃，不属于无人机。如果后续要替换，也建议另建 `OrbitalArt`。
- 推荐使用透明 PNG，主体朝上，四周留少量透明边距。
- 推荐主图命名为 `1.png`，如果有变体可以继续放 `2.png`、`3.png`。
